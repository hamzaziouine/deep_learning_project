# Authors

This project was developed by a 3-person team for the S8 Deep Learning module at Université Internationale de Rabat (academic year 2025–2026).

## Team

**Hamza Ziouine** — *System architecture & orchestration lead*
Designed the overall multi-agent pipeline, wired the CrewAI hierarchical workflow, owned the human-in-the-loop approval gate, and integrated the runtime components end-to-end.

**Mohamed Nacir** — *Agent development & integration lead*
Implemented the individual CrewAI agents (Market Researcher, Sentiment Analyst, Manager), the supporting tools (web search, review loader, sentiment classifier), and the JSONL run logger.

**Nour ElHouda Taroujena** — *ML engineering & documentation lead*
Owned the sentiment-classification model lifecycle: dataset preparation from Amazon Reviews 2018, RoBERTa fine-tuning on RTX 3060, evaluation pipeline, ablation studies, and the bulk of the written report.
